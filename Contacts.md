# Contact Sheet — product notes

Personal directory PDF maker from selected contacts, plus a categorized and tagged master list.

## Core jobs
1. Hold every personal contact in one master list
2. Categories (one per contact) and tag groups for filtering
3. Save named directories (smart-by-tag or fixed selection)
4. Produce a clean printable PDF of a selection or directory

## Not this product
Company CRM / jobs / properties — that lives elsewhere. This repo is Contact Sheet only.
